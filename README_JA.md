# STRAC経営分析 Prototype 02-2.2

## 追加内容
- 右上の「もしも条件」ラベルをスライダー値から自動生成
- 基準値から変更された項目だけ表示
- 例：`もしも条件：売上高110%・人件費90%`
- 変動費率は相対値ではなく実際の率を表示
- 例：`変動費率55.0%`
- 全項目が現在値と同じ場合は `現在値と同じ`
- 下部の説明文にも同じシミュレーション条件を自動反映
- 比較表上部にも「現在のシミュレーション条件」を表示
- 複数条件でもiPadで折り返して表示できるようラベルCSSを調整
