# STRAC経営分析 Prototype 02-2.4

## 変更内容
比較表の「差」の色を、単純な数値の増減ではなく経営上の改善／悪化で表示します。

### 表示ルール
- 売上高：増加＝緑、減少＝赤
- 変動費：単純増減では良否を決めにくいためグレー
- 限界利益：増加＝緑、減少＝赤
- 固定費：減少＝緑、増加＝赤
- 営業利益：増加＝緑、減少＝赤
- 安全余裕率：上昇＝緑、低下＝赤
- 変化なし＝グレー

### 固定費の表示例
- 3,500万円 → 3,300万円：`200万円削減`（緑）
- 3,500万円 → 3,700万円：`+200万円`（赤）
