# STRAC経営分析 Prototype 02-2.5

## 02-2.5の変更内容

- シミュレーションの売上高・人件費・その他固定費に金額入力欄を追加しました。既存のスライダーも使えます。
- スライダー操作は金額欄に反映されます。金額を直接入力すると、スライダーは最も近い位置を示し、計算には入力金額を使います。
- 変動費は「比率で指定」と「金額で指定」を切り替えられます。比率指定では売上高から金額を、金額指定では売上高から比率を計算します。売上高が0円の場合、変動費率は「—」と表示します。
- STRAC図と比較表はシミュレーション条件に連動します。比較表の色分けは以下のルールを引き継ぎます。
- Service Workerのキャッシュ名を `strac-02-2-5-v1` に更新しました。

## 比較表の色分け
比較表の「差」の色を、単純な数値の増減ではなく経営上の改善／悪化で表示します。

### 表示ルール
- 売上高：増加＝緑、減少＝赤
- 変動費：単純増減では良否を決めにくいためグレー
- 限界利益：増加＝緑、減少＝赤
- 固定費：減少＝緑、増加＝赤
- 営業利益：増加＝緑、減少＝赤
- 安全余裕率：上昇＝緑、低下＝赤
- 変化なし＝グレー

### 固定費の表示例
- 3,500万円 → 3,300万円：`200万円削減`（緑）
- 3,500万円 → 3,700万円：`+200万円`（赤）
